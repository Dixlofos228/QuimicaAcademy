## Развёртывание

Подготовлена относительная база Vite и единый обработчик адресов изображений, обложек, иллюстраций завершения и скачивания реестра. Hash-навигация открывает прямые ссылки на уроки без серверных правил перенаправления. Локальный запуск по прежнему адресу сохранён. Надписи RU/ES поясняют, что прогресс хранится в текущем браузере.

GitHub Actions собирает сайт из main, выполняет npm ci, 51 тест расчётов и данных, TypeScript и production build; затем публикует Pages с минимальными правами задачи развёртывания. Actions закреплены на точных SHA. Изменения учебного кода, ресурсов, зависимостей, тестов и конфигурации вызывают новую публикацию; документация и скриншоты её не запускают. Поддержан ручной запуск workflow.

[Последняя проверенная публикация](https://github.com/Dixlofos228/QuimicaAcademy/actions/runs/38859010219) завершилась успешно. HTTPS обязателен. Адрес сайта отвечает HTTP 200.

## Прогресс между устройствами

Прогресс не публикуется и не синхронизируется через GitHub. Он хранится отдельно для каждого браузера и адреса сайта. Данные localhost автоматически не переносятся на HTTPS. Для переноса нужно открыть «Мой прогресс», экспортировать JSON, затем импортировать этот файл в нужном браузере. Курс работает без регистрации.
