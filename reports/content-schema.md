# Course authoring schema
Write a JSON array of Lesson objects to src/data/course-a.json, course-b.json or course-c.json respectively. Types src/types.ts are the contract. ALL displayed fields must be genuine RU and ES pairs {ru:"...",es:"..."}.
Lesson: id (stable ascii), group (ascii e.g. organic/carbs/thermo/protein/lipids/colloids), title, summary, goals (2–3), prereqs (natural text), sourceIds (actual photo ids), paragraphs (at least 3 detailed topic-specific pedagogical paragraphs with title,text,formal,simple), formulas [{tex:KaTeX,symbols}], examples (at least 2 with title,steps [5–9 explicit steps], why [one explanatory sentence per step],result), exercises (4–6 meaningful varied questions), terms (2–4), simulation string, notes optional. additional:true only for added prerequisites.
Exercise: id, type (choice/multi/numeric/formula/order/match/balance/error/steps), question, options optional Lang array, answer numeric OR string OR array of indexes, unit optional, tolerance optional, explanation (specific corrective reasoning), hints array (progressive 2–3).
choice/error answer is zero-based index, numeric numeric answer, formula string. order answer index array permutation of options. multi answer array of correct option indexes. balance numeric array of reaction coefficients with options as species names. match options left terms; answer STRING array of right definitions; engine presents shuffled definitions. steps options labels; answer STRING array of numeric/formula step answers. Use answer numeric iff numeric type. Do not put language-dependent literal expected answers for free text; use formula/numeric/symbolic answers.
Term: id, name,definition,detail,formula optional (KaTeX),example,related optional ids,lessonId optional. Use unique ids and attach lessonId.
Simulation supported ids: bonds, chirality, polarimeter, carbs, energy, thermo, protein, lipids, micelle, dilution, balance. Choose most appropriate; root can extend when needed. No other files except assigned course JSON and analysis reports.
Mark specific illegible source fragments in registry; do not invent archive content. Added exercises must be marked pedagogical new examples in notes, and must have verified solutions. Avoid repeating same lesson across ranges: coordinate themes with root.
