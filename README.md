# Química Academy 2.0

Полный локальный курс RU / ES-UY по школьному архиву química.zip: 9 разделов, 61 урок (4 подготовительных), 123 разобранных примера, 246 упражнений девяти типов, 124 термина и 26 видов интерактивных моделей.

## Открыть и запустить

Адрес: **http://127.0.0.1:4173**. Одна команда в Fish:

```fish
fish /home/mirai/Projects/QuimicaAcademy/start.fish
```

Сервер работает в отдельном процессе и слушает только 127.0.0.1. Команда повторного запуска проверяет, запущен ли он уже. Остановка:

```fish
fish /home/mirai/Projects/QuimicaAcademy/stop.fish
```

Python 3 и Node.js 20+ нужны для запуска. В этой рабочей копии зависимости уже установлены, сборка находится в `dist`. Для новой копии один раз выполните `npm ci` при наличии интернета, затем `npm run build`. После этого сервер и обучение работают без внешнего интернета. Сборка включает локальные изображения, шрифты KaTeX, формулы и данные; внешних API, аналитики и регистрации нет. Исходный ZIP не изменён.

## Начать обучение

Откройте «Начать с основ» или диагностику. В уроке доступны понятное объяснение, формальная запись и кнопка «Объясни ещё проще». Модели меняют вычисления и схемы; процессы можно запускать, останавливать и проходить по шагам. Разобранные примеры сохраняют текущий шаг. Затем выполните практику и мини-тест. Урок отмечается пройденным после правильного решения всех его упражнений.

Общий экзамен включает вопрос из каждого из 61 урока. Есть 61 мини-тест, 9 тестов разделов и входная диагностика: 72 варианта тестирования. Они используют задачи курса; это не 72 независимых набора новых вопросов. Во время теста правильность и объяснения скрыты до завершения. Слабые темы, избранные уроки и результаты видны в «Мой прогресс».

Переключение RU / ES сохраняет текущий шаг и введённые ответы. Светлая и тёмная темы, мобильное меню, управление с клавиатуры и `prefers-reduced-motion` поддерживаются. Испанские фото преподавателя доступны из уроков; по ссылке «Оригинал» открывается неизменённый снимок, а встроенный просмотр использует уменьшенную копию.

## Прогресс и резервная копия

Прогресс хранится в localStorage браузера под ключом `quimica-academy-v1`, без облака. Сохраняются язык, тема, режим объяснения, последний урок, завершённые уроки, попытки упражнений, результаты тестов, избранное и шаги разборов. Экспортируйте JSON на странице прогресса и импортируйте его в другом браузере. Некорректный файл не заменяет текущие данные.

Используйте один адрес `http://127.0.0.1:4173`: `localhost`, другой порт или профиль браузера имеют отдельное хранилище. Очистка данных сайта удаляет прогресс. Резервная копия JSON переносит его вручную.

## Содержание и источники

- `src/data/foundations.json` — добавленные основы.
- `src/data/course-a.json`, `course-b.json`, `course-c.json` — органика, углеводы, термодинамика, равновесие, кислоты/основания, белки, липиды и мыло.
- `reports/inventory.json` — 241 исходный JPEG, размеры и SHA-256.
- `reports/archive-a.json`, `archive-b.json`, `archive-c.json` — результаты визуального просмотра всех страниц.
- `reports/coverage.csv` / `coverage.json` — связь фото → уроки → примеры и упражнения. Копии доступны на сайте.
- `reports/ocr/` — OCR всех 241 фото; распознавание сверялось визуально.
- `reports/archive-integrity.json` — проверка CRC и совпадения 241 оригинала с архивом.
- `reports/scientific-sources*.md` — первичные и официальные научные источники и уточнения.
- `reports/curriculum-*.md` — тематический анализ архива.
- `public/sources/` — копии для просмотра; `public/originals/` — снимки без изменения байтов.
- `reports/FINAL_REPORT.md` — итоговый отчёт и пределы проверки.

76 страниц отмечены для сверки: сюда входят нечёткие рукописные фрагменты, ошибки исходных листов, противоречивые значения и недостаточно заданные условия. Это не означает, что страницы пропущены. Полной достоверной транскрипции каждого рукописного символа нет. Неясные числа не выдаются за установленные данные; научные поправки объяснены в уроках. Внешний QR-ролик не включён. Упражнения курса разработаны по темам архива и явно отделены в реестре от заданий исходных листов; не обещается отдельное решение каждого исходного подпункта.

## Проверки и обновление

```fish
cd /home/mirai/Projects/QuimicaAcademy
npm test
npm run build
python scripts/server.py restart
npm run test:e2e
```

E2E запускается в Chromium (`/usr/bin/chromium`) и Firefox (из кеша Playwright) и локальный сервер на порту 4173. Проверяет все уроки на RU/ES, 482 адреса фото/оригиналов, девять типов заданий, модели, формулы, темы, мобильный экран, JSON, сохранение прогресса и работу с заблокированными внешними запросами. Для новой среды установите тестовый Firefox командой `npx playwright install firefox`; рабочий профиль пользователя не используется. Отчёты: `reports/unit-tests.tap`, `reports/e2e-results.json`, `reports/e2e-artifacts`.

После изменения учебных JSON выполните `python scripts/audit.py`: он обновляет реестр и повторно проверяет исходный архив. Затем соберите и перезапустите сайт. `start.fish` автоматически строит отсутствующий `dist`; при изменении исходников существующий `dist` нужно обновить командой сборки.

Расчётные модели условны и указывают допущения: идеальные разбавленные растворы, фиксированная температура для Kw и удельного вращения, отсутствие потерь в калориметре, схематические молекулы и качественная мицелла. Проверки не заменяют независимую преподавательскую экспертизу всего текста.

## Визуальная лаборатория 2.0

27 лабораторных сцен: 26 типов модели и отдельное сравнение топлива. В каждом уроке работают воспроизведение, пауза, пять фаз, перемотка, скорость 0,5× / 1× / 1,5× и сброс. Изменение параметров пересчитывает научную модель. Текущая фаза имеет пояснение на RU/ES. Молекулы можно поворачивать, приближать, выбирать атомы и изучать подписи; при отсутствии WebGL доступна векторная модель.

54 примера получили пять кадров преобразования формул, 123 разбора — анимированный переход между исходными шагами, запуск, паузу и выбор позиции. Формулы и расчёты сверены с исходными примерами. Различаются количество атомов, количество вещества и единицы результата. Кнопка настроек в верхней панели включает облегчённый режим. Системное уменьшение движения применяется сразу; текст и значения остаются доступны. Таймлайны останавливаются вне экрана и при скрытии вкладки. Three.js загружается по необходимости, WebGL-ресурсы освобождаются при закрытии модели.

Встроенный image_gen действительно создал три оригинальные иллюстрации (главная, фон и завершение); для сайта они сжаты в WebP. Девять собственных SVG-обложек разделов и собственные SVG-иконки составляют общую графическую систему. Художественные изображения служат оформлению; химические структуры, атомный баланс и графики строятся программно. Происхождение изображений: `reports/art-provenance-2.0.json`.

Обновление сохраняет схему `quimica-academy-v1`; при первом чтении существующего корректного прогресса создаёт отдельную копию `quimica-academy-before-2.0`. Настройка графики хранится отдельно в `quimica-visual-settings-v2`. Отказ записи резервной копии не обнуляет прочитанный прогресс. Текущий JSON по-прежнему можно экспортировать со страницы прогресса.

Перед модернизацией создан коммит `adca943` на `main`, ветка `codex/quimica-academy-2` и резервная копия `work/backups/academy-1.0/source-before-2.0.tar.gz`. Исходные фотографии и ZIP сохранены на месте. Повторная SHA-256 проверка: `reports/integrity-2.0.json`. Карта всех 61 урока и новых сцен: `reports/visual-integration-2.0.csv` / `.json`. Итог обновления: `reports/FINAL_REPORT_2.0.md`.

Для повторения измерений производительности: `node scripts/measure-visual-performance.mjs` (параметры и условия записаны в `reports/performance-2.0.json`). Не запускайте параллельно браузерные тесты, если нужен сопоставимый замер. Производительность измеряется по интервалам requestAnimationFrame; это показатель ритма кадров страницы, а не независимая запись кадров композитора.

Новые технологии: Motion и Three.js. После установки зависимостей всё загружается с локального адреса; сетевые службы, профиль Firefox пользователя и настройки Hyprland не меняются.
